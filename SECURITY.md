# Security policy

Report vulnerabilities privately through GitHub Security Advisories. Do not include API keys, session cookies, conversation content, or other user data in an issue.

The latest release receives security fixes. Reports should include affected version, impact, reproduction steps, and any suggested mitigation. We will acknowledge a report within three business days and coordinate disclosure after a fix is available.

ClaudeWatch treats session cookies and Anthropic keys as secrets. They must remain in the OS keychain and must never be logged, committed, or uploaded by the extension.
