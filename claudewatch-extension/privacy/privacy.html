Token Watcher privacy

Token Watcher is local-first. This page explains what is stored, for how long, how to delete it, and what is never collected.

Data stored on this device

Settings, per-provider quota snapshots (up to 7 days), recent token-count events (up to 2,000), and optional local analytics events (up to 90 days). All of it lives in this browser profile's extension storage.

Optional cloud data

None. Token Watcher has no cloud sync and no servers of its own. If you opt in to sharing with Token Watcher Core, metadata-only events go to localhost:7734 on your own computer and nowhere else.

Network requests

The extension contacts only claude.ai, chatgpt.com and gemini.google.com, using your existing signed-in session, to read your own quota figures.

Retention

Quota snapshots are trimmed to the last 7 days, token events to the most recent 2,000, and analytics events to 90 days. Removing the extension deletes everything it stored.

Deleting your data

Use "Delete all analytics data" in Extension Settings to clear local analytics immediately, or remove the extension to clear all stored data.

Never collected

  • Prompt text or response text
  • Attachments, conversation titles, or page contents
  • Cookie values, API keys, or passwords
  • Full URLs, or any data sold or shared with third parties
